The extracted JSON datasets preserve the upstream BC coordinate convention.
Source files, repository tree identifiers, numerical precision and transformations
are documented in dist/data/provenance.json. Original notices and license text
are retained. Dataset extraction and browser code were prepared on 2026-10-14.

The JavaScript numerical implementation is an independent browser adaptation.
It is not an official release or endorsement by the upstream author. Numerical
representation identifiers and bases are not claimed to be the original BC,
CDML or Bilbao labels or gauges. No Wolfram kernel or binary .mx database is
included or executed.

The supplied trace example is an explicitly truncated excerpt of the original
MSGCorep Mn3NiN example, not a new or complete physical calculation. Its source,
retained rows and changed k-point count are recorded in
dist/examples/provenance.json. The ordinary SG186 parser-test fixture is likewise
an attributed excerpt of an upstream SpaceGroupIrep example.
