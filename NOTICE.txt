2. MSGCorep
   Author identified by the upstream package: Gui-Bin Liu
   https://github.com/goodluck1982/MSGCorep
   Upstream license: GNU General Public License, version 3.
   License copy: dist/licenses/MSGCorep-GPL-3.0.txt

The extracted JSON datasets preserve the upstream BC coordinate convention.
Source files, repository tree identifiers, numerical precision and transformations
are documented in dist/data/provenance.json. Original notices and license text
are retained. Dataset extraction and browser code were prepared on 2026-10-14.

The Python numerical implementation and earlier JavaScript regression reference
are independent browser adaptations.
It is not an official release or endorsement by the upstream author. Numerical
representation identifiers and bases are not claimed to be the original BC,
CDML or Bilbao labels or gauges. No Wolfram kernel or binary .mx database is
included or executed.

The supplied trace example is an explicitly truncated excerpt of the original
MSGCorep Mn3NiN example, not a new or complete physical calculation. Its source,
retained rows and changed k-point count are recorded in
dist/examples/provenance.json. The ordinary SG186 parser-test fixture is likewise
an attributed excerpt of an upstream SpaceGroupIrep example.

Additional projects integrated on 2026-10-15:

3. MagneticTB — https://github.com/zhangzeyingvv/MagneticTB
   Commit 3575e8356af282c9d9447bfbf03e282ef3bac77d
   GNU GPL version 3 (GPL-3.0-only).
   See upstream/MagneticTB and dist/licenses/MagneticTB-LICENSE.txt.
   NumPy adaptation of symmetry-constrained tight-binding workflow and numerical
   band/topology analysis. It does not load the upstream native Rust extension
   and does not implement all symbolic, fitting or spin-space-group interfaces.

4. CrystKit — https://github.com/hongyi-zhao/CrystKit
   Commit 0f4f85e31d8166bb5a3e3474287449fa5572d5fd
   GNU GPL version 2 or (at your option) any later version.
   See upstream/CrystKit and dist/licenses/CrystKit-LICENSE.txt.
   Python adaptation of exact affine and matrix group tools with certified
   three-dimensional reference matching. The 2026-10-16 extension includes CARAT Q catalogs and exact
   cohomology; it is not a complete GAP/PCP compatibility layer. This combined derivative is under GPL version 3.

Upstream copyright and authorship notices are preserved in the reference source
files. Detailed source hashes and scope are in dist/data/python-provenance.json.
Pyodide and numerical dependencies are downloaded from their pinned public CDN
packages at runtime and retain their own upstream licenses. No calculation data
is sent to that CDN. Python modules also run locally with CPython.

5. CARAT — https://github.com/lbfm-rwth/carat
   Commit 65619d6ae4ec911c8cf7aa3c9fa09866a0d36ab9
   Exact Q-class catalogue extraction and independent Python classification.
   GPL-2.0-or-later; original license: dist/licenses/CARAT-LICENSE.txt.
   See upstream/CARAT and dist/data/carat/manifest.json for source and hashes.
   Z-class/affine counts are upstream metadata, not a claim of complete Python
   enumeration. Symbolic and group-extension additions use SymPy exact arithmetic.

Further exact Python algorithms added on 2026-10-16:
   carat_integral.py: constructive prime-cyclic integral/affine classes and
   certified modular-neighbour classification using independent CARAT counts.
   integral_normalizer.py: arithmetic module, lattice glue and Schreier methods.
   symbolic_interfaces.py: exact supplied-data representation/corepresentation,
   cyclotomic, intertwiner and symbolic geometry interfaces.
   These are independently implemented finite-resource algorithms, not a claim
   of full CARAT/GAP/Mathematica compatibility. Coverage and proof boundaries are
   retained in README.md and dist/data/python-provenance.json.

Further arithmetic and symbolic coverage on 2026-10-16:
   arithmetic_centralizer.py: saturated endomorphism orders, rational central
   idempotents, split-module units with lattice glue, definite norm units,
   real quadratic Pell units and certified normalizer lifts.
   finite_conductor.py: finite maximal-order conductor intervals and exact
   multiplicity-lattice orbits, with explicit completeness and resource status.
   symbolic_spacegroups.py: automatic exact SG/MSG little representations,
   Wigner corepresentations, full-star induction and original-name JSON aliases.
   crystkit_extensions.py: exact torsion, orientability and translation center.
   Supported arithmetic models and parameter strata are documented separately;
   this release does not assert complete upstream signature compatibility or
   that all higher-dimensional catalogue classes have been precomputed.

Structure standardization uses the original SpaceGroupIrep getBCsymmetry.py BC settings (Gui-Bin Liu, GPL-3.0), with a Python parser/converter and the official spglib 2.8.0 C library compiled to WebAssembly (BSD-3-Clause). See dist/vendor/spglib/LICENSE.spglib and provenance.json.

BC standard labels are derived from the original SpaceGroupIrep tables.
Bilbao maximal-k labels and character tables are redistributed from IrRep
(https://github.com/irreducible-representations/irrep), commit
4f43f138d30ef37a499a297ac9b1ec8ef14717cc, under GPL-3.0.
See dist/licenses/IrRep-LICENSE.txt, dist/data/labels/manifest.json and the
unmodified table snapshot dist/data/labels/bilbao-source.zip. Missing and
ambiguous source labels are preserved; magnetic corepresentation labels
are outside this standard-label dataset.

The 32 crystallographic point-group course (2026-10-18) contains original
Chinese explanations, examples, exercises and interactive illustrations.
Its pedagogical reference is M. S. Dresselhaus, G. Dresselhaus and A. Jorio,
Group Theory: Application to the Physics of Condensed Matter, Springer (2008),
https://doi.org/10.1007/978-3-540-32899-5. The textbook PDF, page images and
original figures are not redistributed. Chapter/page references are recorded
in dist/data/pointgroup-lessons.json and dist/docs/pointgroup-course.md.
The point-group atlas and character tables are independently computed in
Python from the existing attributed SpaceGroupIrep data; their source and
numerical validation are included with the atlas and its build script.
